# Support

LogShield is a pre-alpha, single-maintainer project. There is no support SLA.

- **Questions and ideas**: open a [feature request](https://github.com/TurlaFSB/logshield/issues/new/choose) or a GitHub Discussion if enabled.
- **Bugs**: open a bug report with the version (`logshield -version`), the flags used, and a minimal request that reproduces it. Use only inert payloads.
- **Security issues**: never in a public issue. See [SECURITY.md](SECURITY.md).
