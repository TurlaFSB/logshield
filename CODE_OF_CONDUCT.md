# Code of Conduct

LogShield follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Welcome newcomers, assume good faith, give and
accept technical criticism of the work without making it personal, and focus on
what is best for the project and its users.

Unacceptable behavior includes harassment, discrimination, personal attacks,
trolling, publishing others' private information, and anything that would be
unwelcome in a professional setting.

## Security research

Good-faith security research on this project is welcome and is governed by
[SECURITY.md](SECURITY.md). Do not test against systems you do not own or have
written authorization to test.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code and
may restrict participation. Report concerns privately through GitHub (a security
advisory draft or a message to the maintainer, [@TurlaFSB](https://github.com/TurlaFSB)).
Reports are handled confidentially.
